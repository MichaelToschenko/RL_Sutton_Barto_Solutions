## О проекте

Репозиторий содержит решения всех 140 упражнений из книги Саттона и Барто
«Введение в обучение с подкреплением» (Reinforcement Learning: An Introduction).

Две части, связанные между собой:

* `solutions/` — сборник решений на LaTeX. `main.tex` только подключает главы,
  сами решения лежат в `solutions/chapters/chNN.tex` (по файлу на главу книги;
  в главах 14–16 упражнений нет). Собирается **pdflatex** — из-за `T2A` и
  `inputenc` xelatex не подойдёт без правки преамбулы.
* `notebooks/` — упражнения, требующие вычислительного эксперимента. Имя файла
  соответствует номеру упражнения: `07_02.ipynb` — упражнение 7.2.

## Правила работы с репозиторием

* **Ноутбуки хранятся вместе с выводами.** Именно они делают решения читаемыми
  прямо на GitHub, поэтому очищать вывод (nbstripout и подобное) нельзя.
* **Никакого `tqdm.notebook` и `tqdm.auto`** — только `from tqdm import tqdm`.
  Виджетные выводы GitHub не отрисовывает, ячейка выглядит пустой.
* Иллюстрации разделены по происхождению: `solutions/figures/own/` — собственные
  графики, `solutions/figures/book/` — сканы из книги. В `\includegraphics`
  указывается только имя файла, каталоги подставляет `\graphicspath`.
* После правки глав или списка ноутбуков нужно обновить оглавление README:
  `python3 tools/build_index.py`. CI проверяет это и падает, если README отстал.
* PDF не коммитится: его собирает GitHub Actions и публикует на Pages и в релиз
  `latest`.

## Скрипты

| | |
|---|---|
| `tools/build_pdf.sh` | сборник целиком и по PDF на главу, в `solutions/build/` |
| `tools/build_index.py` | пересобирает оглавление в README (`--check` для CI) |
| `tools/build_pages.py` | каталог для GitHub Pages со страницей-указателем |
| `tools/fix_notebooks.py` | нормализация ноутбуков перед публикацией |
| `tools/split_tex.py` | одноразовая разрезка исходного монолита, сохранён для истории |
